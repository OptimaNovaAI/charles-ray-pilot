Installing a skill takes about a minute

  1. Download the file above. It stays a .zip, do not unzip it.
  2. In Claude, open Settings, then Capabilities, then Skills.
  3. Choose Upload skill and pick the file.
  4. Start a new chat and ask for it in the words shown on the card.
